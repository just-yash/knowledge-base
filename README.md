## What This Is

This repository is not a collection of notes.
It is a **working system for thinking**.

Built as a public Zettelkasten, it captures ideas in motion — incomplete, connected, and continuously refined.

---

## Purpose

* Think in public
* Build clarity through writing
* Connect ideas across domains
* Document learning as it happens

This is not optimized for presentation.
It is optimized for understanding.

---

## Scope

The content spans multiple domains:

* Computer Science (DSA, systems, fundamentals)
* Cybersecurity
* Artificial Intelligence
* Mathematics
* Psychology & Philosophy
* Writing (poetry, reflections)

The goal is not breadth.
The goal is **depth over time**.
