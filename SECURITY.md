## Reporting a Vulnerability

If you discover a potential security vulnerability or private data exposure within this repository, please do **NOT** open a public issue.

Instead, please report security concerns privately:
- **Email**: `yashagrawall333@gmail.com`
- **Response Time**: We aim to acknowledge and investigate security reports within 24–48 hours.

---

## Vault Data Exclusions

Private notes and unpublished folders should be listed in `SKIP_DIRS` inside `build-vault.js` to ensure they are excluded from web compilation.
