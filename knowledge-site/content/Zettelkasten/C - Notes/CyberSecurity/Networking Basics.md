- Sharing of peripherals and resources
- Network gaming 
### What is the **Internet**?
- it's a vast network that connects computers all over the world.
- Through the internet, people can share information and communicate from anywhere with an Internet Connection.

# TCP/IP
**Transmission Control Protocol** & **Internet Protocol**
- Rules that define how data travels on the internet.
- Consider this as the *Traffic Light System* of the *Internet Roads*.

# Client-Server Model
![[Pasted image 20251115192926.png]]
- All the devices connected to the internet are *Clients* (eg: Phone connected to the WiFi).
- *Servers* are computers that store webpages, sites, etc. When a client device wants to access a webpage in downloaded form the server onto the client machine to be displayed in the user's web browser.

# What is IP Addresses?
- Real web addresses aren't nice memorable strings. They are special numbers that look like this : 142.250.185.68 (This is an IPv4 address.)
- It represents a unique location on the web. 
- These aren't easy to remember hence we have **DNS(Domain Name Servers)**.

# DNS
- Domain Name Server
- Invented to translate IP addresses into Human Readable Texts.
- Websites can also be reached directly via their IP addresses.
- When you type the domain name of the website, the browser converts it into their real IP address. 

# DHCP
- Dynamic Host Configuration Protocol
- It is needed to simplify the assignment of IP addresses.
- It is uses to dynamically assign the IP addresses to devices on the network so they can communicate efficiently. 
- It automates and manages the assignment of IP addresses.
- It is the reason why we havent yet ran out of IPv4 addresses.

# MAC Address
- Media Access Control
- MAC address is worldwide unique address.
- Its uses Alpha-numeric(Hexadecimal) format.

# Ports(Network Ports / Software Ports / Digital Ports)
- A single IP can handle only 1 type of traffic at a time.
- Ports enables the IP to use multiple channels within that single channel. 
- A port is simply a channel of communication which is numbered between 1 and 65,535. 
- Each port is dedicated to a different type of traffic.
	- Port 20,21 is used for FTP : File Transfer Protocol
	- Port 53 : DNS : Domain Name Server
	- Port 22 : SSH : Secure Shell
	- Port 80 : HTTP : Hyper Text Transfer Protocol
	- Port 443 : Hyper Text Transfer Protocol Secure.
