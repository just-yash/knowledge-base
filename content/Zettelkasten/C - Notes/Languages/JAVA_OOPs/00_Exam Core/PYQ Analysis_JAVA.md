Here's the complete 4-agent analysis of your IGIT OOP Java papers (2021-25). Use the tabs to navigate each section. Key takeaways:

**The 5 programs you absolutely must know cold:**

1. The digit-product series via command-line arguments — appears every single year
2. Banking application using interface + package + custom exception — appears every year, growing in complexity
3. Area/perimeter using abstract class + multilevel inheritance
4. 3-thread synchronization program with is Alive, join, and Priority
5. Scrolling/blinking applet + multithreading combo

**The shift to watch for in 2025:** Questions now consistently follow the "True or False → Justify (1 mark) + Write a program (4 marks)" pattern. Preparing just the concept theory or just the code is no longer enough — you need both.

**Safe to skip:** JDBC and JavaFX have never appeared in any paper despite being in the syllabus.
