# Errors
- Very helpful while debugging
- They tell us exactly what went wrong and where

---
# Types of Errors

## 1. Compile-Time Errors
- Includes :
	- Syntax Errors
	- Semantic/Type Errors
- Anything caught before Execution

---
## 1.1 Syntax Errors
- Violation of language grammar
- The language translator  (Compiler / Interpreter / Assembler) simply cannot understand the code
- Detected before Execution
- Prevents program form running
- Easy to fix once spotted

---
## 1.2 Semantic Errors
- Meaning Errors
- Syntax is correct but meaning is wrong.
- Often caught by compiler 
- Related to data types and incompatible operations

---
## 2. Runtime Errors
- Occurs while program is running
- Program Compiles but crashes or terminated during execution. 

### Runtime Error Handling → Exception Handling
- Exception Handling 
	- If the language supports → Robust Programming
	- try-catch / try-except / try-finally blocks
	- Prevents abnormal program termination
	- allows Graceful recovery

Runtime error → crash  
Runtime exception → controlled failure

---
## 3. Logical Errors
- Program runs successfully, but fails to produce the desired output. 
- No Compiler warning 
- No crash 
- Generally difficult to catch and fix
- Solved by Testing and Debugging

---
## 4. Linker Errors 
- Function declared but not found.
- Compilation succeeds
- Linking fails
