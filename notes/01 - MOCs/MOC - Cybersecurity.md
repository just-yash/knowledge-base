# Purpose 

> Why does this MOC exist? 
This MOC maps the cybersecurity knowledge domain — from Linux foundations and networking basics to ethical hacking methodology — so the full skill stack is navigable in one place.

> What problem does it solve? 
Security notes on Linux, networking, hacking stages, and lab setup were spread across separate files with no connection. This MOC links them into a learning progression.

> What does mastering this domain enable?
Mastering cybersecurity enables penetration testing as a monetisable skill, strengthens the multi-camera surveillance research with real threat-model thinking, and builds the AI + cybersecurity positioning you are working toward.
