# Purpose 

> Why does this MOC exist? 
This MOC maps all data structures and algorithm knowledge — from arrays and linked lists to trees, sorting algorithms, and recursion — into a single navigable structure for both learning and revision.

> What problem does it solve? 
DSA notes were split across Algorithm/ and DS/ subfolders with no unified view. This MOC connects every concept into a progression from fundamentals to advanced structures.

> What does mastering this domain enable?
Mastering DSA is essential for GATE preparation, technical interviews, and implementing efficient algorithms in the multi-camera surveillance research pipeline.
