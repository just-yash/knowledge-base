# FLAT Notes 2

- Symbols : Anything used to represent something 
	- Letters are Symbols 
- Alphabets : finites non empty set of symbols 
	- ∑ is used for depicting alphabets 
	- ∑ = {0,1}
- String : finite sequence of symbols which are the member of the set alphabet 
	- ∑ = {a, b} 
	- String : aabb, aa, b, …. 
	- Words are Strings  
- Language : Set of strings 
	- set of predefined words and grammar 
	- words → sentence 
	- program : string
