Trend Analysis

Pattern 1 — True/False + Justify + Program is the new standard

From 2023-24 onward, almost every 5-mark question follows: a conceptual True/False statement (1 mark) + a program (4 marks). Prepare both the concept and the code side-by-side for every topic.

Pattern 2 — The digit-product series program recurs every year

Across all 4 years, a variant of 1 ± x²/2! ± x⁴/4! … xⁿ/n! appears, where x = sum/product of consecutive digits or prime digits of a number passed via command-line. This is the single most repeated program — know it cold.

Pattern 3 — Banking application evolves each year

2022-23: class + object only. 2023-24: interface + package + custom exception (10-mark). 2024-25: interface + package + custom exception (5-mark, plus a separate custom exception question). Always implement the full version with interface, package, and custom exception.

Pattern 4 — Short notes Q8 is always "Any Two" from four options

Options consistently include: Exception vs Error, Interface vs Abstract class, Throw vs Throws, AWT hierarchy / Delegation Event Model / Modifiers / Constructor overloading. Prepare Exception vs Error and Interface vs Abstract class — they appear most often.

Pattern 5 — Applet + multithreading always paired

In all 4 years, an applet question is paired with multithreading (scrolling message, blinking message, moving ball). Knowing applet alone or threads alone is not enough — you need the combination.

Pattern 6 — AWT vs Swing always asked with delegation event model

Q7 consistently covers both AWT/Swing comparison and event-handling GUI programs. Prepare a JLabel+JTextField+JButton calculator program as your go-to template.

Last-Day Revision — Top 15 Predicted Questions

1. Write a Java program to compute the series 1 - x²/2! + x⁴/4! - x⁶/6! + … xⁿ/n! where x = sum of product of consecutive digits of num and n = sum of product of consecutive prime digits, taking num via command-line argument.
2. Write a Java program using interface and package to perform deposit, withdraw, check balance for a banking application. Assign minimum balance Rs. 2500. Deduct 10% penalty if deposit below minimum balance. Show InsufficientFundException for withdraw.
3. What are the differences between abstract class and interface? Write a program to find area, perimeter and volume of Rectangle, Square and Circle using multilevel inheritance, abstract class and method overriding.
4. Explain the thread lifecycle with a state diagram. Write a program to create 3 threads that print first name, middle name, and last name using Synchronization, isAlive, join with Priority 9, 8, 7 respectively.
5. Define Applet. Describe its lifecycle with a neat diagram. Which lifecycle states occur only once vs multiple times? Write a Java program to create a scrolling message using applet and multithreading, taking input from user via JOptionPane.
6. What is AWT? How does it differ from Swing? Explain the delegation event model with neat architecture. Write a program to create a calculator using JLabel, JTextField, JButton and ActionListener.
7. What is the difference between Checked and Unchecked Exception? Write a program to find division of two numbers using try, catch and finally block.
8. Constructor returns nothing — True or False? Justify. Write a program to find the volume of 3 boxes where dimension of first box is known to user, second box is double of first, third box is the sum of first and second, using constructor overloading.
9. Method overloading is possible by simply changing the return type — True or False? Justify. Write a program to find sum of two numbers, sum of two strings, and sum of two complex numbers using method overloading.
10. Write a program to find the difference between Sum of product of consecutive even digits (except 2 and 6) and Sum of product of consecutive odd digits (except 3 and 7) of any 4-digit number using conditional operator, without looping or decision making, taking input via command-line arguments.
11. Synchronization is unavoidable in multithreading — True or False? Justify. Write a Java program to print your first name and last name using synchronization.
12. Which method is used to call the paint() method of applet? Write a program to print a message from user via JOptionPane that blinks and scrolls using applet and multithreading.
13. Write short notes on: (a) Exception vs Error  (b) Interface vs Abstract class  (c) Throw vs Throws  (d) Delegation Event Model — Answer any two.
14. Abstract class is better than interface — True or False? Justify. Explain modifiers that cannot be used with interface and why.
15. What is Deadlock? Explain the process of deadlock detection and recovery using suitable examples. Also define multithreading and its significance in Java.
