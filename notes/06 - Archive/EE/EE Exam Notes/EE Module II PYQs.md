###### A1)
###### I)
1. Stages of Law of Variable Proportion

- Stage I: Increasing returns
- Stage II: Diminishing returns
- Stage III: Negative returns

2. Stage I: Increasing Returns (Not chosen)

- Total Product ($TP$) increases at increasing rate up to the point of inflection
- Marginal Product ($MP$) and Average Product ($AP$) reach their maximum values 
- Fixed factors (land, etc) are underutilized
Rationale
- Stopping here means the producer is leaving potential efficiency gains unexploited 
- adding more variable inputs still increases the average output per unit
- Resources are not fully utilized
- Producer can increase output further at lower cost
- Not a rational stopping point

3. Stage II: Diminishing Returns (Chosen Stage)

- Total Product ($TP$) increases but at a decreasing rate
- Marginal Product ($MP$) decreases but remains positive
- This stage represents balanced use of factors

Rationale
- Optimum utilization of fixed and variable factors
- Marginal Product ($MP$) > 0 ensures output is still increasing
- No overcrowding of inputs
- Cost per unit becomes minimum
- Maximum profit can be achieved

4. Stage III: Negative Returns (Not chosen)

- Total Product ($TP$) decreases
- Marginal Product ($MP$) becomes negative
- Average Product ($AP$) decreases but remains positive
- Excess variable input causes inefficiency

Rationale
- variable factors such as labour are over-used
- Additional input reduces output
- Cost increases sharply
- Leads to losses

5. Conclusion

- Producer always operates in Stage II
- Because it is the only rational stage with efficient resource use and profit maximization

**Increasing Returns to Scale (IRS) - Definition**

- When a given proportionate change in all inputs leads to a greater proportionate change in output, it is known as Increasing Returns to Scale
- It is also known as Economies of Scale

**Example:**

- Land = 3, Labour = 3, Output = 100
- Land = 6, Labour = 6, Output = 300 (output more than doubled when inputs doubled)

###### Q2, Q1.III)
**Increasing Returns to Scale:**

- When a given proportionate change in inputs leads to a greater proportionate change in output, it is known as Increasing Returns to Scale
- Output increases more than proportionately to the increase in inputs

**Diminishing Returns to Scale:**

- When a given proportionate change in inputs leads to a lesser or less than proportionate change in output, it is known as Diminishing Returns to Scale
- The output changes by a smaller proportionate amount than the change in inputs

**Stage chosen by Producer:**

- A rational producer will always choose the 1st stage, i.e., the Stage of Increasing Returns to Scale for production

**Reasons:**

- In the 1st stage, the fixed factor is not optimally used, so adding more variable factors increases output more than proportionately
- In the 2nd stage, both the fixed and variable factors are used economically and efficiently
- In the 2nd and 3rd stages, the variable factor is being used too much compared to the fixed factor
- In the 3rd stage, MP becomes negative, so no rational producer will produce here
- A rational producer will always choose the 1st stage because:
    - Cost per unit is falling
    - Output is increasing more than proportionately
    - MP is positive and rising
    - TP increases at an increasing rate

###### Q3) 
| What does production function mean? What are the differences between short run and long run production functions? | 5 Marks | (2023 Q3a) |
| ----------------------------------------------------------------------------------------------------------------- | ------- | ---------- |

###### A3) 
**Production Function - Definition:**

- Production means the creation of utilities, i.e., the transformation of inputs into outputs
- Production function is the functional relationship between the inputs and the outputs
- It shows the maximum output that can be produced from a given set of inputs

**Factors of Production:**

- There are 4 factors of production:
    1. Land
    2. Labour
    3. Capital
    4. Organisation/Entrepreneur

- It is expressed as:
$$Q = f(\text{Land, Labour,Capital, Organization})$$

- where $Q$ = output

**Short Run Production Function:**

- Short run is a period of time in which at least one factor of production is fixed and cannot be changed
- The fixed factor is usually capital
- In the short run, only variable factors can be changed
- It is governed by the Law of Variable Proportions
- Production function in short run:
Example : Capital and Labour
$$Q = f(\overline{K},Labour)$$

- where $$\bar{K}$$ denotes capital is fixed  
So, $100 = (\overline{1}, 10)$    
⇒ $120 = (\overline{1}, 12)$

**Long Run Production Function:**

- Long run is a period of time in which all factors of production are variable
- No factor remains fixed in the long run
- It is governed by the Laws of Returns to Scale
- Production function in long run:
Example : 
$$Q = f({Capital},Labour)$$

So, $100 = (1, 10)$    
⇒ $150 = (2, 12)$

- where both L and K are variable

**Differences between Short Run and Long Run Production Function:**

|Basis|Short Run|Long Run|
|---|---|---|
|Factors|At least one factor is fixed|All factors are variable|
|Law|Law of Variable Proportions|Laws of Returns to Scale|
|Time|Short period|Long period|
|Flexibility|Less flexible|More flexible|
|Output change|Only variable factor changes output|All factors change output|

**Key Points:**

- In short run, a producer can keep some factors constant and vary others
- In long run, a producer can vary all factors and adjust the scale of production
- eg: Labour is variable in both short run and long run
- Capital is fixed in short run but variable in long run

###### A4) 
**Returns to Scale - Introduction:**

- Returns to scale refers to the change in output when all inputs are changed in the same proportion
- It is a long run concept since in the long run, all factors of production are variable
- There are 3 laws of returns to scale:
    1. Increasing Returns to Scale
    2. Constant Returns to Scale
    3. Diminishing Returns to Scale

**1. Increasing Returns to Scale (IRS):**

- When a given proportionate change in inputs leads to a greater proportionate change in output, it is known as Increasing Returns to Scale
- Output increases more than proportionately to the increase in inputs

$\text{If inputs increase by } x\% \Rightarrow \text{output increases by more than } x\%$

- Example from notes:

|Land|Labour|Output|
|---|---|---|
|1|2|100|
|2|4|300|
![[Pasted image 20260330002309.png]]
- Output more than doubled when inputs doubled
- Reason: Indivisibility of factors, specialization, technical and managerial economies

**2. Constant Returns to Scale (CRS):**

- When a given proportionate change in inputs leads to an equal proportionate change in output, it is known as Constant Returns to Scale
- Output changes in the same proportion as the change in inputs

$\text{If inputs increase by } x\% \Rightarrow \text{output increases by exactly } x\%$

- Example from notes:

|Land|Labour|Output|
|---|---|---|
|1|2|100|
|2|4|200|
![[Pasted image 20260330002338.png]]
- Output doubled exactly when inputs doubled
- The output will change proportionately

**3. Diminishing Returns to Scale (DRS):**

- When a given proportionate change in inputs leads to a lesser or less than proportionate change in output, it is known as Diminishing Returns to Scale
- Output increases less than proportionately to the increase in inputs

$\text{If inputs increase by } x\% \Rightarrow \text{output increases by less than } x\%$

- Example from notes:

|Land|Labour|Output|
|---|---|---|
|1|2|100|
|2|4|150|

![[Pasted image 20260330002349.png]]
- Output increased by less than double when inputs doubled
- Reason: Managerial inefficiency, limited natural resources, coordination problems

###### A5. I, II, III) 
**Cost:**

- Cost is the functional relationship between the output and the cost of production
- It refers to the expenses/expenditures incurred for manufacturing a product
- Cost function is expressed as:

$C = f(\text{output})$

**Types of Cost:**

**1. Total Fixed Cost / Supplement Cost:**

- Fixed cost refers to those costs which do not change with the change in output
- It remains constant irrespective of the level of production
- It is also known as overhead cost
- eg: rent, insurance, machinery cost
- Total fixed cost curve is horizontal in nature
![[Pasted image 20260330004213.png]]

**2. Total Variable Cost:**

- Variable cost refers to those costs which change with the change in output
- It increases proportionately with the increase in production
- eg: raw material cost, labour wages
- Variable cost increases as output increases
![[Pasted image 20260330004242.png]]

**3. Total Cost / Prime Cost:**

- Total cost is the sum of total fixed cost and total variable cost
- Prime Costs are directly proportional to output
$$TC = TFC + TVC$$
![[Pasted image 20260330004345.png]]

**4. Marginal Cost:**

- Marginal cost is the change in total cost due to the production of one additional unit of output
$$MC = \frac{\Delta TC}{\Delta Q}$$
![[Pasted image 20260330005132.png]]

**5. Average Cost:**

- Average cost is the cost per unit of output
$$AC = \frac{TC}{Q}$$
**6. Opportunity Cost:**

- Opportunity cost is the cost of the next best alternative product
- eg: if a producer chooses to produce product X, the opportunity cost is the profit foregone from producing product Y

**7. Explicit Cost:**

- Costs which are directly paid by the producer
- expenditure outside the organisation
- eg: wages, rent, raw material cost

**8. Implicit Cost:**

- Costs which are not directly paid by the producer but are incurred
- eg: depreciation, opportunity cost
- If a tractor is rented → Explicit cost 
- If a tractor is bought → Implicit cost

**REVENUE:**

**Definition:**

- Revenue is the amount of money received by a producer from the sale of his product
- It is the income earned by selling the output in the market

$$Profit = TR - TC$$

**Types of Revenue:**

**1. Total Revenue (TR):**

- Total revenue is the total amount received from the sale of all units of output
$$TR = Price \times Quantity$$

**2. Average Revenue (AR):**

- Average revenue is the revenue received per unit of output sold
$$AR = \frac{TR}{Q}$$
- AR is also known as the demand curve of the product

**3. Marginal Revenue (MR):**

- Marginal revenue is the change in total revenue due to the sale of one additional unit of output
$$MR = \frac{\Delta TR}{\Delta Q}$$
- In a monopoly market: AR > MR
![[Pasted image 20260330005519.png]]
- In a perfectly competitive market: AR = MR = price
![[Pasted image 20260330005547.png]]
- MR can be negative but AR can never be negative

###### III) 
**Marginal Cost - Definition:**

- Marginal cost is the change in total cost due to the production of one additional unit of output
- It is the addition made to the total cost when one more unit is produced
- It can be positive, negative or zero (though practically it is always positive)
$$MC = \frac{\Delta TC}{\Delta Q}$$​
- where:
    - $\Delta TC$ = change in total cost
    - $\Delta Q$ = change in output (always 1 unit)
- It can also be written as:
$$MC = TC_n - TC_{n-1}$$
- where $TC_n$ = total cost of n units and $$TC_{n-1}$$ = total cost of $n-1$ units
![[Pasted image 20260330005132.png]]

**Key Properties of Marginal Cost:**

- MC is independent of fixed cost
- MC only depends on variable cost
- When MC is falling, AC is also falling
- When MC is rising and is less than AC, AC is still falling
- When MC = AC, AC is at its minimum
- When MC > AC, AC is rising
- MC curve is U-shaped in nature

**Importance of Marginal Cost:**

1. Helps in Price Determination:
    - MC helps the producer in deciding the price of the product
    - A producer will always produce at a point where MC = MR for maximum profit
2. Helps in Production Decision:
    - MC helps the producer in deciding how much to produce
    - If MC < MR, the producer should increase production
    - If MC > MR, the producer should decrease production
    - If MC = MR, the producer is at equilibrium
3. Helps in Profit Maximization:
    - The condition for profit maximization is MC = MR
    - MC helps in identifying this point
4. Helps in Cost Control:
    - MC helps in identifying the additional cost incurred for each unit of production
    - This helps the producer in controlling costs
5. Helps in Policy Making:
    - Governments use MC in determining tax policies
    - It helps in determining subsidies and price controls
6. Helps in Identifying Economies of Scale:
    - When MC is falling, it indicates economies of scale
    - When MC is rising, it indicates diseconomies of scale

**Relationship with other costs:**
$$MC = \frac{\Delta TVC}{\Delta Q}$$$$MC=\frac{\Delta TVC}{\Delta Q}$$​
- Since fixed cost does not change, MC is only affected by variable cost
- This is why MC is also defined as the change in total variable cost due to production of one additional unit
