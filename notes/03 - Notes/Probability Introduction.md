# Random Experiment 

- Experiment which satisfies the following conditions : 
	- It should have more than one outcome 
	- outcomes are non predictable 

###### Example : 
- Tossing of fair/unbiased [[Coin]]
- Rolling of fair / unbiased [[Dice]]

---
# Outcome 

- Result of random experiment 

###### Example : 

| Random Experiment          | Outcome          |
| -------------------------- | ---------------- |
| Tossing of a Fair [[Coin]] | H, T             |
| Rolling of a Fair [[Dice]] | 1, 2, 3, 4, 5, 6 |

---
# Sample Space 

- Set of outcomes of [[#Random Experiment]]
- Each individual element of the Sample Space is called **Sample Point**

| Random Experiment          | Outcome          | Sample Space           |
| -------------------------- | ---------------- | ---------------------- |
| Tossing of a Fair [[Coin]] | H, T             | S = {H, T}             |
| Rolling of a Fair [[Dice]] | 1, 2, 3, 4, 5, 6 | S = {1, 2, 3, 4, 5, 6} |

### Representation 

1. [[Set]] form : $S = \\\{\lambda_{1}, \lambda_{2}, \\dots , \lambda_{n}\\\}$

# Event of a Random Experiment 

- Event is subset of [[#Sample Space]]  
- if $|S| = n$ 
	- Total no. of Events = $2^n$

###### Example : 
- 2 Coins are tossed simultaneously 
	- S = {TT, TH, HT, HH}
- E1 = At least 1 T should occur = {TT, TH, HT}
- E2 = Exactly 2 H should occur = {HH}
