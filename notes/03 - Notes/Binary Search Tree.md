# Binary Search Tree / Ordered Tree / Sorted Binary Tree 

- Left subtree < node < right subtree 
- Operations : insertion of elements, deletion of elements and lookup (checking whether a key is present)

---
## Advantage 

- Major advantage of BST over other data structures is that the related sorting algorithm and search algorithm such as in-order traversal can be very efficient 
- Its very easy to code 

| Algorithm | Average case     | Worst case |
| --------- | ---------------- | ---------- |
| Space     | $O(n)$           | $O(n)$     |
| Search    | $O(\log_{2}{n})$ | $O(n)$     |
| Insert    | $O(\log_{2}{n})$ | $O(n)$     |
| Delete    | $O(\log_{2}{n})$ | $O(n)$     |

---
## Deletion of elements 

---
### Case 1 : Deleting Leaf Nodes 

- Its the easiest as there is no dependency, so we can simply remove it.  

---
### Case 2 : Deleting Internal Nodes / Root Node

- step 1 : Write the in-order traversal 
- step 2 : Consider the elements on either side of the node (generally we consider the predecessor → left node) 
	- Predecessor cant be the parent node of the node 
	- it should be from it left subtree
	- If there is no valid predecessor then consider the successor → right node
- step 3 : Replace the node with its valid alternative 
- step 4 : Repeat the deletion process to delete the alternate from its original position 

---

###### Q3) A binary search tree is generated by inserting in order the following integers:  50,15,62,5,20,58,91,3,8,37,60,24. The number of nodes in the left subtree and right subtree of the root respectively is ? (GATE 1996) (1 Marks)

###### Q7) The number of ways in which the numbers 1,2,3,4,5,6,7 can be inserted in an empty binary search tree, such that the resulting tree has height 6, is ? Note: The height of a tree with a single node is 0. (GATE 2015) (2 Marks)

A7) 64  

> For having the maximum height, for every node(except the last position), you have two choice, i.e. the extreme elements, in the end you will have only one option. 
> Total no. of cases : 2<sup>n-1</sup> = 2<sup>h</sup> = 2<sup>6</sup> = 64

###### Q8) When searching for the key value 60 in a binary search tree, nodes containing the key values 10, 20, 40, 50, 70, 80, 90 are traversed, not necessarily in the order given. How many different orders are possible in which these key values can occur on the search path from the root to the node containing the value 60? (GATE 2007) (1 Marks)
###### a) 35
###### b) 64
###### c) 128
###### d) 5040

A8) a) 35  

> For all these values to be traversed, they must come before 60. 
> If they come before 60 their order is fixed 
> 10 → 20 → 40 → 50 and 90 → 80 → 70 
> Restricted PnC ⇒ $\frac{7!}{4! \times 3!} = 35$
