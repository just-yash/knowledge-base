# CNN 

---
## Core Idea 

- Convolution Neural Network
- Deep learning architecture primarily designed for 
	- image processing 
	- video analysis
	- object detection 
	- facial recognition 
	- medical imaging 
	- surveillance systems 
	- autonomous driving 
- CNNs automatically learn : 
	- spatial patterns
	- textures
	- edges
	- shapes 
	- hierarchical visual features 
- CNNs do not require manual feature extraction
