# Future Works

1. Academic / Institutional Systems
	1. Classroom  
		- Automatic Attendance using cameras 
		- Classroom monitoring 
			- track student engagement 
			- detect disturbance or abnormal activity 
	2. Examination 
		- Verify candidate identity at entry 
		- check if the student is sitting at its designated place
		- detect cheating :
			- frequent head turns
			- looking sideways
			- interaction with others
			- Cheating using external sources like chits, mobile phones, etc.

2. Security & Surveillance 
	1. Multi-Camera Surveillance System and Threat Detection System 
		- Track individuals across cameras 
		- Maintain identity across locations 
		- Real-time monitoring 
		- Detect suspicious behavior patterns 
		- Identity abnormal movement or loitering 
	2. Restricted Area Access Control 
		- Allow only authorized individuals
		- Detect unauthorized entry 
	3. Crown Monitoring & Tracking 
		- Track individuals in dense environments (Religious gathering, events, fairs, airports and stations, etc.)
	
3. Workplace Attendance & Tracking 
	- Employee attendance automation 
	- including timestamps 
	- Employee activity monitoring 

4. Retail Analytics 
	- Track customer movement 
	- behaviour analysis (time spent, interest areas)
	- security (useful in jewellery and other shops)

5. Photo/Video Organization 
	- Cluster photos and videos by person 
	- auto create albums 

6. Home Surveillance System 
	- identify known v/s unknown individuals 
	- Auto alert theft 
	- Divide individuals in the Categories 
		- Red : unknown individuals 
		- Yellow : known individuals but not family members 
		- Green : Family members / trusted individuals 

7. Advanced / Research-Oriented 
	 1. Multi-Modal Identity Fusion Systems 
		 - Combines : Face + Body + Motion 
		 - improves robustness v/s face-only 
	 2. Behaviour-Aware AI Systems 
		 - Combine identity + behavior 
		 - Detect intent, not just presence 

---

> All applications share the same core pipeline (detection → embedding → matching → tracking → ReID), but differ in the final application layer and evaluation metrics.
