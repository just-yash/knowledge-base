# DB Users & Administrators

---
## DBA (Database Administrator) (The 1st User)

- Authorised access to the DB
- Co-ordinating and Monitoring DB use
- Acquiring software and hardware resources as needed
- Security 
- if DB is slow (poor response time) → DBA is answerable 

---
## DB Designer (The 2nd User)

- Identifies the data to be stored in the DB
- Chooses the appropriate structure to store and represent data 

---
## End User 
- Queries DB System 
- Updates DB 
- Generates Report 

The End User can be of Different Types : 

### Casual End-User 
- Managers 
- Use DB when required 

### Naive and Parametric User 
- A sizeable portion of DB is used by this user 
- The sizeable DB is called **canned transaction**  

### Sophisticated End User 
- Used by this user when highly required 

### Standalone User 
- Maintains personal DB by using readymade programmable DB 

### System Analysts and Application Programmer 
- Tests and debugs the program 

### Workers behind the scene 
- They don't interact with the DB directly 
- They are : 
	- #### DBMS System Designer and Implementors 
	- #### Developers / Tool Developers 
	- #### Operators and maintenance personnel
