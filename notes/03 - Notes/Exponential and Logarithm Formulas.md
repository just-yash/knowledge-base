# Exponential and Logarithm Formulas 

---

# EXPONENTIAL LAWS

- Product rule:
  $a^m \cdot a^n = a^{m+n}$

- Division rule:
  $a^m / a^n = a^{m-n}$

- Power of power:
  $(a^m)^n = a^{mn}$

- Power of product:
  $(ab)^n = a^n b^n$

- Power of fraction:
  $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$

---

# SPECIAL EXPONENT CASES

- $a^0 = 1$  (for $a \neq 0$)

- $a^{-n} = \frac{1}{a^n}$

- $a^{\frac{1}{n}} = \sqrt[n]{a}$

- $a^{\frac{m}{n}} = \sqrt[n]{a^m}$

---

# IMPORTANT EXPONENTIAL FORMS

- $$e^x$$ (natural exponential)

- $e^{x+y} = e^x \cdot e^y$

- $e^{-x} = \frac{1}{e^x}$

---

# LOGARITHM DEFINITION

- $$\log_a b = x \iff a^x = b$$

---

# BASIC LOG LAWS

- Product rule:
  $$\log_a(xy) = \log_a x + \log_a y$$

- Division rule:
  $$\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y$$

- Power rule:
  $$\log_a(x^n) = n \log_a x$$

---

# SPECIAL LOG VALUES

- $\log_a 1 = 0$

- $\log_a a = 1$

- $\log_a \frac{1}{x} = -\log_a x$

---

# CHANGE OF BASE

- $$\log_a b = \frac{\log_c b}{\log_c a}$$

- Common logs:
  - $\log_{10} x = \log x$
  - $\log_e x = \ln x$

---

# EXPONENTIAL–LOG RELATION

- $$a^{\log_a x} = x$$

- $$\log_a (a^x) = x$$

---

# IMPORTANT IDENTITIES

- $$\log_a b \cdot \log_b c = \log_a c$$

- $\log_a b = \frac{1}{\log_b a}$

---

# INEQUALITIES (IMPORTANT)

- If $a > 1$:
  - $x > y \Rightarrow \log_a x > \log_a y$

- If $0 < a < 1$:
  - $x > y \Rightarrow \log_a x < \log_a y$

---

# DOMAIN CONDITIONS (VERY IMPORTANT)

- For $\log_a x$:
  - $x > 0$
  - $a > 0$, $a \neq 1$

---

# EXPONENTIAL EQUATIONS

- If $a^x = a^y$, then:
  - $x = y$

- If $a^x = b$:
  - $x = \log_a b$

---

# LOGARITHMIC EQUATIONS

- Combine logs first using rules  
- Convert to exponential form  

---

# APPROXIMATIONS (HIGH VALUE)

- $$e^x \approx 1 + x \quad (\text{for small } x)$$

- $$\ln(1 + x) \approx x$$

---

# GROWTH & DECAY

- Exponential growth:
  $$y = ae^{kt}$$

- Exponential decay:
  $$y = ae^{-kt}$$

---

# CORE FORMULAS SUMMARY

- $$\log_a(xy) = \log_a x + \log_a y$$

- $$\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y$$

- $$\log_a(x^n) = n \log_a x$$

- $$\log_a b = \frac{\log b}{\log a}$$

- $$a^{\log_a x} = x$$

- $$\ln(1 + x) \approx x$$
