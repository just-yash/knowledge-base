# Processors
## General Purpose
### 1. CPU
- (Central Processing Unit) 
- General Purpose Processor for Logic and Control. 
### 2. APU
- (Accelerated Processing Unit)
- CPU + GPU hybrid for efficiency. 
### 3. MPU
- MicroProcessor Unit
- The CPU used in microcontrollers and embedded systems. 
### 4. MCU
- MicroController Unit
- CPU + Memory (RAM) + I/O (Input/Output) in a compact embedded system 

## Parallel & Graphics Processing 
### 1. GPU
- Graphics Processing Unit
- Handles Parallel Visual and compute workloads
### 2. SPU
- Stream Processing Unit
- Stream- based computation
- Core element inside GPUs
### 3. PPU
- Physics Processing Unit
- Handles simulations of physical systems
- Now merged into GPUs
### 4. VPU
- Vector Processing Unit
- Specialized in performing vector/matrix arithmetic
- Used in CPUs and HPC systems
### 5. GPGPU 
- General Purpose GPU 
- Using GPUs for non-graphic computation (scientific, AI, etc. ).
