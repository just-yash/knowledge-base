# Complex Numbers 

---

# BASIC DEFINITION

- A complex number:
  $$z = a + ib$$

- Real part: $\operatorname{Re}(z) = a$  
- Imaginary part: $\operatorname{Im}(z) = b$

- $i = \sqrt{-1}$, with:
  - $i^2 = -1$
  - $i^3 = -i$
  - $i^4 = 1$ (cycle repeats)

---

# MODULUS AND ARGUMENT

- Modulus:
  $$|z| = \sqrt{a^2 + b^2}$$

- Argument:
  $\arg(z) = \tan^{-1}\left(\frac{b}{a}\right)$ (adjust quadrant)

---

# CONJUGATE

- Conjugate:
  $$\overline{z} = a - ib$$

- Important results:
  - $z \cdot \overline{z} = |z|^2$
  - $|z_1 z_2| = |z_1||z_2|$
  - $\overline{z_1 z_2} = \overline{z_1} \cdot \overline{z_2}$

---

# POLAR FORM

- $$z = r(\cos\theta + i\sin\theta)$$
  where $r = |z|$, $\theta = \arg(z)$

---

# EULER FORM

- $$z = re^{i\theta}$$

- $$e^{i\theta} = \cos\theta + i\sin\theta$$

---

# MULTIPLICATION & DIVISION (POLAR)

- Multiplication:
  $$z_1 z_2 = r_1 r_2 \, \text{cis}(\theta_1 + \theta_2)$$

- Division:
  $$\frac{z_1}{z_2} = \frac{r_1}{r_2} \, \text{cis}(\theta_1 - \theta_2)$$

---

# DE MOIVRE’S THEOREM

- $$[r(\cos\theta + i\sin\theta)]^n = r^n (\cos n\theta + i\sin n\theta)$$

---

# ROOTS OF COMPLEX NUMBERS

- $$z^{1/n} = r^{1/n} \, \text{cis}\left(\frac{\theta + 2k\pi}{n}\right), \quad k = 0,1,...,n-1$$

---

# GEOMETRIC INTERPRETATION

- Complex number ↔ point $(a,b)$ in plane  
- $|z|$ = distance from origin  

---

# IMPORTANT IDENTITIES

- $$|z_1 + z_2| \le |z_1| + |z_2|$$  (Triangle inequality)

- $|z_1 - z_2| \ge ||z_1| - |z_2||$

---

# STANDARD RESULTS

- If $|z| = 1$, then:
  - $z\overline{z} = 1$

- If $z = x + iy$:
  - $|z|^2 = x^2 + y^2$

---

# ARGUMENT PROPERTIES

- $\arg(z_1 z_2) = \arg z_1 + \arg z_2$

- $\arg\left(\frac{z_1}{z_2}\right) = \arg z_1 - \arg z_2$

---

# LOCUS (IMPORTANT)

- $|z - z_0| = r$ → circle  
- $|z - z_1| = |z - z_2|$ → perpendicular bisector  

---

# EXPONENTIAL FORM (ADVANCED USE)

- $$e^{i\theta} = \cos\theta + i\sin\theta$$

- $$\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$$

- $$\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$$

---

# IMPORTANT TRICKS (LEEE FOCUS)

- Multiply by conjugate to simplify division  
- Convert to polar form for powers/roots  
- Use geometry for locus questions  

---

# CORE FORMULAS SUMMARY

- $$z = a + ib$$

- $$|z| = \sqrt{a^2 + b^2}$$

- $$z = r(\cos\theta + i\sin\theta)$$

- $$e^{i\theta} = \cos\theta + i\sin\theta$$

- $$[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$$
