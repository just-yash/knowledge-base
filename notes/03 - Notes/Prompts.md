# YouTube Notes Extraction 
```prompt
Convert the provided YouTube video or transcript into detailed and structured Obsidian notes.

Follow the format strictly.

STRUCTURE RULES

Use proper Markdown headings:

# → Main topic  
## → Subtopic  
### → Concept / explanation  
#### → Detailed explanation  
###### → Examples always  

FORMATTING RULES

1. Use short bullet points.
2. Maintain clear topic → subtopic hierarchy.
3. Use 4-space indentation for nested bullets.
4. Separate major sections with:

---

5. Use Obsidian internal links where relevant:
[[Topic Name]]

6. Do NOT mention the video, timestamps, or speaker.
Focus only on the concepts and knowledge.

TABLES

When explaining structures (like K-Maps, truth tables, etc.), include clear Markdown tables.

MATHEMATICAL EXPRESSIONS

Use LaTeX for formulas. Use the correct syntax for LaTeX. 

Inline:
$expression$

Block:
$$
expression
$$

EXAMPLES

Examples must always be under:

###### Example

Examples may include:
- tables
- solved expressions
- logical reasoning
- worked problems

DIAGRAMS

Include diagrams where necessary using:
- ASCII diagrams
- truth tables
- K-Maps
- flow structures

QUESTION FORMAT

When questions appear, format them as:

###### Q1) Question text

Answer format:

A1) answer

Include reasoning if necessary.

SUMMARY SECTION

At the end include:

# Summary

Provide concise revision points.

REFERENCES SECTION

At the end include:

# References

Include relevant links if available.

WRITING STYLE

- Concise
- Technical
- Bullet-based
- Information-dense
- Do not omit important details
- Maintain logical flow between topics

OUTPUT REQUIREMENT

Return clean Markdown formatted specifically for Obsidian.
```
