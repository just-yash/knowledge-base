# Sorting
![[animation of sorting algorithms.gif]]
- The process of arranging data (numbers or characters) in a specific order (increasing or decreasing).  
- Crucial in many application that require data to be in order.  

- **Space Complexity**:  
	- **Internal Sorting (In-Place)**: Sorting that requires no extra memory beyond what is needed for the problem itself (Eg: Heap Sort)  
	- **External Sorting**: Sorting that requires additional memory to store data (Eg: Merge Sort)  
- **Stability**:  
	- If a Sorting algorithm **preserves the relative order of equal elements** then its considered **Stable**. (Eg: Bubble Sort)  
	- If the sorting algorithm **doesn't preserve the order of equal elements** then is considered **Unstable** (Eg: Insertion Sort)
