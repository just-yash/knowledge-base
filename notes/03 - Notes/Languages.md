> Language is how one entity communicates with other.

# Types of Languages

# 1. Human Languages (Natural Languages)
- Evolved organically in Human Societies

---
## A. Spoken Languages
- Used primarily in speech

Eg : English, Hindi, Spanish, Mandarin, etc

---
## B. Written Languages
- Visual Representation of Spoken Language. 

Eg : 
- Latin Script (English, French, etc)
- Devanagari (Hindi, Sanskrit, etc)
- Arabic Script

---
## C. Sign Languages
- Gestural language with grammar. 
- Sign Languages are not gesture for spoken languages. 
- They are independent languages with their own grammar.

Eg : 
- ASL(American Sign Language)
- ISL (Indian Sign Language)

---
# 2. Computer Languages
- Languages designed to instruct computers. 
---
## A. Low-Level Languages
- Close to hardware.

### I. Machine Language 
- 1<sup>st</sup> Generation Language(1GL) 
- Executed directly by CPU
- Binary (0s and 1s)

### II. Assembly Language
- 2<sup>nd</sup> Generation Language(2GL) 
- Human-Readable mnemonics → ADD, SUB, MUL, etc
- Mnemonics were not understood by Computers
	- Language Translator called Assembler is required to convert Assembly Language to Machine Language
- Hardware Specific

Eg :
```nginx
MOV AX, BX
```
---
## B. High-Level Programming Languages
- 3GL
- Closer to human thinking. 
- Portable, Easier to read
- Abstracted from hardware

> A _programming paradigm_ is a style or approach to solving problems.

---
### I. Procedural Programming Paradigm
- Program is a sequence of step-by-step instructions
- Focus on procedures (functions)

Characteristics:
- Top-down approach
- Uses functions and variables
- Emphasizes algorithmic steps

Examples:
- [[C]]
- Pascal
- Fortran

---
### II. Object-Oriented Programming ([[OOPs]]) Paradigm
- Program organized around objects
- Objects contain data and methods

Core Concepts:
- Encapsulation
- Inheritance
- Polymorphism
- [[DB System Concepts#Data Abstraction|Abstraction]]

Characteristics:
- Models real-world entities
- Improves code reuse and maintainability

Examples:
- Java
- C++
- [[Python]]

---
### III. Functional Programming Paradigm
- Computation based on mathematical functions
- Avoids changing state and mutable data

Characteristics:
- Functions are first-class citizens
- Emphasis on immutability
- No side effects (ideally)

Examples:
- Haskell
- Lisp
- Erlang
- Scala

---
### IV. Logic Programming Paradigm
- Program consists of facts and rules
- Execution via logical inference

Characteristics:
- You describe _what is true_
- System determines _how to solve_

Example:
- Prolog

---
## C. Declarative / Domain - Oriented Languages
- 4GL
	- very high [[DB System Concepts#Data Abstraction|abstraction]] 
	- narrow domain focus
	- Minimal Code
	- Productivity over Control
- No algorithms
- You decide What to do → Computer decides How to do

Eg : 
- SQL
- MATLAB
- R
- SAS
- ABAP

---
## D. Constraint-Based / Logic Languages
- 5GL
	- Logic-based
	- Constraint solving
	- Heavy AI influence 
	- Miniman Procedural code
- You describe facts, Rules, Goals.

Eg :
Prolog

---
## E. Markup / Description Languages (Declarative, Non-Programming)
- High-level declarative description languages
- Used to define structure and formatting 
- Not used for computation

Eg : 
- HTML
- XML
- [[Markdown]]
- CSS

These are not 3GL-5GL → generation classification applies only to programming language.

---
# Practical Reality
- Generational classifications do **not** have strict boundaries.
- Many modern languages are **multi-paradigm** and span multiple generations conceptually.

Example:
- Python shows characteristics of 3GL, 4GL, and limited 5GL styles.
