# Basics_C

- Created by Dennis Ritchie at Bell Labs in 1972.
- Latest version C23
- Used in 
	- Operating Systems
	- Programs inside devices like cars, home electronics, etc
	- software that needs to be fast, including databases and system tools
	- game engines and programs that handle graphics
- C is a Procedural Language → You build programs with functions
- C++ → extension of C → similar syntax → it supports classes and objects → used in OOPs(Object Oriented Programming)
- Case Sensitive Language
- With the help of C we can create both [[Software#Application Software|Application Software]] as well as [[Software#System Software|System Software]].

# Middle Level Language
- C is a middle level language
- Along with being high level it can 
	- access memory addresses
	- manipulate bits
	- perform pointer arithmetic
	- control memory allocation manually 
- But its not completely [[Languages#A. Low-Level Languages|low level]] either
	- compiler handles registers
	- compiler handles instruction selection
	- portable across architectures

> C is [[Languages#B. High-Level Programming Languages|High Level]] by Category but Middle Level by Capability.

# Compilation Steps of C
- Source Code(.c) → Compiler → Object Code(`.obj` / `.o`) → linker for libraries → executable file(`.exe` / `.out`) → Loader 

- `.obj` ; `.exe` → windows 
- `.o` ; `.out` → Linux

**Linker** → A type of [[Software#System Software|system software]] which is used to combine libraries and object code(`.obj`) to make executable file (`.exe`)
- Resolves external function and variable references
- Combines multiple object files into one program 
- Links standard and user-defined libraries 
- generates final executable file

**Loader** → A type of [[Software#System Software|system software]] that loads an executable file (`.exe`) from secondary storage (disk) into primary memory (RAM) and prepares it for execution.
- Loads program into memory
- Allocates required memory
- Performs relocation
- Links dynamic libraries (if needed)
- Starts program execution

---
# Files created for each C program 
1. Source Code (`.c`)
	- Contains the C program written by the programmer
	- Human-readable
	- Input to the compiler
2. Object Code (`.obj` / `.o`)
	- Generated by the compiler
	- Contains machine-level instructions
	- Not executable
	- May have unresolved references to libraries
3. Executable File (`.exe` / `.out`)
	- Generated by the linker  
	- Fully linked and runnable
	- Loaded into memory by the loader
4. Backup File (`.bak`) → Optional Files → Editor Dependent, not language dependent
	- Created automatically by some editors or IDEs
	- Stores a backup of the source file
	- **Not created by the compiler**
	- Used for recovery if the original file is lost or corrupted
	- Not part of C compilation process

# Indentations in C
- Indentations in C are purely for aesthetics → readability. They have no meaning. Compiler only check for `;`.

# Summary 
- C is a procedural, case-sensitive programming language created in 1972.
- Used for OS, embedded systems, system utilities, databases, and performance-critical software.
- Classified as high-level but offers low-level capabilities (memory access, pointers).
- Program translation flow: Source → Object → Executable → Memory.
- Compiler converts source to object code.
- Linker combines object code with libraries.
- Loader places executable into RAM and starts execution.
- Core strength of C: efficiency, portability, and fine-grained control.
