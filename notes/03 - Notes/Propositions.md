# Propositions

- a declarative sentence that is either **True (T)** or **False (F)**, but not both.
- They should be stating a fact or have some factual information. 
- **Commands**, **Exclamatory** sentences or **interrogatory** sentences are **not** Propositions 
- **Ambiguous** statements are **not** Propositions

### Examples :
- `3 + 2 = 5`         This can only be `True`. Hence its a Proposition     
- `3 + 5 = 5`         This can only be `False`. Hence its a Proposition
- `x + y = 5`         This can be both. Hence its not a Proposition
- `He is Tall.`     This can be both. Hence its not a Proposition
- `Get Out.`           This can be neither. Hence its not a Proposition
- `What a Car!`      This can be neither. Hence its not a Proposition
- `Who are you?`    This can be neither. Hence its not a Proposition

- `This sentence is True.`    
	- If we consider this sentence `True`. Then `True` is `True`. Hence its `True`.
	- But if we consider this sentence `False`. Then `True` is `False`, which is `False`.
	- This can be both. Hence its not a Proposition.

### Liar's [[Paradox]]
- `This sentence is False.`
	- This is Liar's [[Paradox]]
	- If we consider this sentence `True`. Then `False` is `True`, which is `False`. So It cant be `True`
	- But if the sentence is `False`. Then `False` is `False`, which is `True`. 
	- A [[Paradox]] cannot give a `Stable Truth Value`. 

###### Other Examples : 
- `I am Lying.`

# Mental Mode
- Don't think if this sentence can be both `True` or `False`. Think that can it be both `True` and `False` at the same time. 

# Truth Value
- the value of a Proposition. Is it `True` or `False`. 
###### Example : 
- `4 is a Prime Number`. 
	- This is a Proposition
	- Truth Value : `False`
