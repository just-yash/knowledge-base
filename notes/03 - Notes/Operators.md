# Operators
> An **operator** is a symbol that performs an operation on one or more operands.

# Types of Operators
## 1. Arithmetic Operators

| Operator | Meaning             |
| -------- | ------------------- |
| `+`      | Addition            |
| `-`      | Subtraction         |
| `*`      | Multiplication      |
| `/`      | Division            |
| `%`      | Modulus → Remainder |

---
## 2. Relational Operators
- Comparison Operator
- Compares two values
- Results is true (1) or false (0)

| Operator              | Meaning               |
| --------------------- | --------------------- |
| `=​=` → double equals | check equality        |
| `!=`                  | not equal to          |
| `>`                   | greater than          |
| `<`                   | less than             |
| `>=`                  | greater than or equal |
| `<=`                  | less than or equal    |

---
## 3. Logical Operators
- Used with Conditions

| Operator          | Meaning     |
| ----------------- | ----------- |
| `&&`              | Logical AND |
| `\|\|` → two \|\| | Logical OR  |
| `!`               | Logical NOT |

---
## 4. Assignment Operators
- Assign values to variables

| Operator | Meaning                       |
| -------- | ----------------------------- |
| `=`      | Assign                        |
| `+=`     | Add and assign                |
| `-=`     | Subtract and assign           |
| `*=`     | Multiply and assign           |
| `/=`     | Divide and assign             |
| `%=`     | Modulus(Remainder) and assign |

---
## 5. Unary Operators
- Operates on one operand

| Operator | Meaning     |
| -------- | ----------- |
| `+`      | Unary plus  |
| `-`      | Unary minus |
| `++`     | Increment   |
| `--`     | Decrement   |
| `!`      | Logical NOT |

---
## 6. Bitwise Operators
- Operate on bits

| Operator         | Meaning     |
| ---------------- | ----------- |
| `&`              | Bitwise AND |
| `\|` → single \| | Bitwise OR  |
| `^`              | Bitwise XOR |
| `~`              | Bitwise NOT |
| `<<`             | Left Shift  |
| `>>`             | Right Shift |
